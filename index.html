快速开始

环境要求

LangChain 需要 Python 3.10 及以上版本，官方 Quickstart 示例使用 3.11。

安装 LangChain

建议在虚拟环境里安装：

python3.11 -m venv .venv

# macOS / Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

pip install -U langchain

Codex

Codex 是 OpenAI 的 AI 编程助手，可以帮助你阅读代码、修改代码、排查问题、写文档、跑测试、做代码审查，也可以通过插件、技能、MCP 和自动化扩展工作流。

这个模块按实际使用场景整理 Codex 的核心功能。

学习路线

  1. 快速开始：了解 Codex 能做什么，以及第一次使用时怎么提需求。
  2. 版本控制：理解 Codex 和 Git、分支、提交、PR 的关系。
  3. 工作区与 Worktree：学习如何隔离任务改动，避免影响当前代码。
  4. 代码修改与审查：让 Codex 修改代码、解释改动、检查风险。
  5. 技能 Skills：用可复用流程增强 Codex 的专业能力。
  6. 插件 Plugins：用插件打包技能、工具、MCP 和配置。
  7. MCP：让 Codex 连接外部系统和私有数据源。
  8. 自动化：创建提醒、定时检查和持续跟进任务。
  9. 常见问题：整理使用中最容易混淆的问题。

MCP

MCP 可以理解为 Codex 连接外部工具和数据源的一种协议。通过 MCP，Codex 可以访问本地工具、公司系统、文档平台、数据库、浏览器自动化能力等。

MCP 能做什么

  • 查询外部文档。
  • 读取授权后的私有数据。
  • 调用项目专用工具。
  • 操作浏览器或其他应用。
  • 把团队内部系统接入 Codex。

什么时候需要 MCP

  • Codex 需要实时数据，而不是只读本地文件。
  • Codex 需要访问私有系统。
  • Codex 需要调用一个稳定的外部工具。
  • 单靠命令行或文件读写不够。

工作区与 Worktree

Worktree 可以让同一个 Git 仓库同时拥有多个独立工作目录。Codex 做较大任务时，可以在隔离目录中修改代码，避免影响你当前正在编辑的内容。

什么时候使用 Worktree

  • 当前分支上已经有未提交改动。
  • 要尝试一个不确定的方案。
  • 要并行处理多个功能或 bug。
  • 不希望 Codex 的实验性修改影响主工作区。

常见问题

Codex 会自动提交代码吗

一般不会。Codex 可以修改文件，但是否提交通常由你决定。你可以明确要求它提交，也可以自己使用 Git 提交。

Codex 会覆盖我的代码吗

Codex 应该先检查当前工作区状态，并避免覆盖无关改动。为了更安全，可以在需求中明确说：

不要覆盖我已有的未提交改动。
