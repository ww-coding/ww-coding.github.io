Codex

Codex 是 OpenAI 的 AI 编程助手，可以帮助你阅读代码、修改代码、排查问题、写文档、跑测试、做代码审查，也可以通过插件、技能、MCP 和自动化扩展工作流。

这个模块按实际使用场景整理 Codex 的核心功能。

学习路线

  1. 快速开始：了解 Codex 能做什么，以及第一次使用时怎么提需求。
  2. 版本控制：理解 Codex 和 Git、分支、提交、PR 的关系。
  3. 工作区与 Worktree：学习如何隔离任务改动，避免影响当前代码。
  4. 代码修改与审查：让 Codex 修改代码、解释改动、检查风险。
  5. 技能 Skills：用可复用流程增强 Codex 的专业能力。
  6. 插件 Plugins：用插件打包技能、工具、MCP 和配置。
  7. MCP：让 Codex 连接外部系统和私有数据源。
  8. 自动化：创建提醒、定时检查和持续跟进任务。
  9. 常见问题：整理使用中最容易混淆的问题。

Git

Git 是日常开发中最常用的版本控制工具。本目录整理 Git 的基础命令、分支协作、常见问题处理以及 rebase、reset 等进阶操作，方便按场景快速查找。

内容目录

  • 基础操作：初始化仓库、提交修改、查看状态与差异。
  • 分支管理：创建、切换、关联、查看和删除分支。
  • 问题排查：TortoiseGit safe.directory、reset 后未暂存变更等常见问题。
  • 高级操作：rebase、合并 commit、rebase 后无法 push 等协作场景。
