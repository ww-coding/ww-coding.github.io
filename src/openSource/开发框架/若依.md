# 若依

## 项目简介

若依是一套面向个人和企业的开源快速开发平台，提供权限管理和常见后台管理能力。它有单体、前后端分离和微服务等不同版本，可以根据项目规模和技术架构进行选择。

若依微服务版本采用 Spring Boot、Spring Cloud 和 Spring Cloud Alibaba，前端基于 Vue。注册中心和配置中心使用 Nacos，权限认证使用 Redis，流量控制使用 Sentinel，分布式事务使用 Seata。

## 核心特点

- 提供用户、角色、菜单、部门和权限等常见后台管理功能。
- 同时覆盖单体、前后端分离和微服务架构。
- 后端采用主流 Java 生态技术，便于二次开发和团队维护。
- 提供基于 Vue 3、Element Plus 和 Vite 的前端版本。
- 项目完全开源，可用于学习、原型验证和业务系统开发。

## 适用场景

- 快速搭建企业后台管理系统。
- 学习 Spring Boot、Spring Cloud Alibaba 与 Vue 的项目整合。
- 在成熟权限模型基础上进行业务功能二次开发。
- 根据团队需求选择单体或微服务项目模板。
