# LangChain

LangChain 是用于开发大语言模型（LLM）应用的框架，把模型调用、提示词、工具、记忆、检索等能力组合成可复用的应用。官方文档现在统一在 [docs.langchain.com](https://docs.langchain.com/oss/python/langchain/overview)。

本目录记录 LangChain 的学习过程与实践总结，知识点以官方文档为准，示例只保留可复现的最小片段。

## 内容目录

- [学习路线](./LangChain/学习路线.md)：按官方文档的模块顺序整理学习顺序和对应地址。
