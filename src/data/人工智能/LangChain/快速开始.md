# 快速开始

## 环境要求

LangChain 需要 Python 3.10 及以上版本，官方 Quickstart 示例使用 3.11。

## 安装 LangChain

建议在虚拟环境里安装：

```bash
python3.11 -m venv .venv

# macOS / Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

pip install -U langchain
```

如果项目使用 uv：

```bash
uv python pin 3.11
uv init
uv add langchain
```

模型和各类集成放在独立的 provider 包里，用到哪个装哪个：

```bash
# OpenAI
pip install -U langchain-openai

# Anthropic
pip install -U langchain-anthropic
```

## 配置模型密钥

在 shell 或 `.env` 文件里配置密钥，例如 OpenAI：

```bash
export OPENAI_API_KEY="your-api-key"
```

::: warning
不要把真实密钥写进代码或提交到 Git，笔记和仓库里只保留占位符。
:::

## 第一个 Agent

```python
from langchain.agents import create_agent


def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
)
print(result["messages"][-1].content_blocks)
```

要点：

- `create_agent` 负责把模型、工具和系统提示组装成一个可调用的 Agent。
- 模型字符串使用 `provider:model` 格式，换供应商通常只需要改这一行并配置对应密钥。
- 工具的 `docstring` 会成为提示的一部分，写清楚用途能明显提升调用准确率。

## 观察调用过程

需要排查 Agent 中间步骤时，可以开启 LangSmith 追踪：

```bash
export LANGSMITH_TRACING="true"
export LANGSMITH_API_KEY="..."
```
