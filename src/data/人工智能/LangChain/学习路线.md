# 学习路线

官方文档把内容分成“入门 → 核心组件 → 中间件 → 进阶 → 生产”几个层次，这里按同样的顺序整理，方便对照学习、按需查阅。

## 1. 入门

- [安装](https://docs.langchain.com/oss/python/langchain/install)：安装 `langchain` 和所需的 provider 包。
- [Quickstart](https://docs.langchain.com/oss/python/langchain/quickstart)：用 `create_agent` 跑通第一个 Agent。
- [设计理念](https://docs.langchain.com/oss/python/langchain/philosophy)：理解 LangChain 为什么要这样抽象。

## 2. 核心组件

- [Agents](https://docs.langchain.com/oss/python/langchain/agents)：Agent 的构成与运行方式。
- [Models](https://docs.langchain.com/oss/python/langchain/models)：模型初始化与参数配置。
- [Messages](https://docs.langchain.com/oss/python/langchain/messages)：消息类型与上下文组织。
- [Tools](https://docs.langchain.com/oss/python/langchain/tools)：把函数暴露给模型调用。
- [短期记忆](https://docs.langchain.com/oss/python/langchain/short-term-memory)：多轮对话的状态保存。
- [流式输出](https://docs.langchain.com/oss/python/langchain/streaming)：逐步返回结果。
- [结构化输出](https://docs.langchain.com/oss/python/langchain/structured-output)：让模型返回可解析的数据。

## 3. 中间件

- [中间件概览](https://docs.langchain.com/oss/python/langchain/middleware/overview)：在 Agent 执行过程中插入逻辑。
- [内置中间件](https://docs.langchain.com/oss/python/langchain/middleware/built-in)：官方已提供的能力。
- [自定义中间件](https://docs.langchain.com/oss/python/langchain/middleware/custom)：按业务需要扩展。

## 4. 进阶用法

- [检索（RAG）](https://docs.langchain.com/oss/python/deepagents/retrieval)：接入外部知识。
- [长期记忆](https://docs.langchain.com/oss/python/langchain/long-term-memory)：跨会话保存信息。
- [上下文工程](https://docs.langchain.com/oss/python/langchain/context-engineering)：控制喂给模型的内容。
- [人在回路](https://docs.langchain.com/oss/python/langchain/human-in-the-loop)：关键步骤人工确认。
- [护栏](https://docs.langchain.com/oss/python/langchain/guardrails)：约束模型行为。

## 5. 生产化

- [部署](https://docs.langchain.com/oss/python/langchain/deploy)：把 Agent 发布成服务。
- [可观测性](https://docs.langchain.com/oss/python/langchain/observability)：用追踪定位线上问题。

## 学习建议

1. 先跑通 Quickstart，再回头补概念，比按目录顺序硬啃更容易建立整体感。
2. 每个组件都自己写一个最小示例，记到本目录对应笔记里。
3. 官方文档更新较快，遇到 API 对不上时先查 [更新日志](https://docs.langchain.com/oss/python/releases/changelog)。
