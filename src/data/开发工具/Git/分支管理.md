# Git 分支管理

## 创建本地分支并关联远程分支

### 创建本地分支

```bash
git branch 分支名
```

例如：

```bash
git branch dev
```

这条命令会基于当前分支创建本地分支 `dev`。

### 切换本地分支

```bash
git checkout 分支名
```

例如：

```bash
git checkout dev
```

### 创建并切换分支

```bash
git checkout -b 分支名
```

例如：

```bash
git checkout -b dev
```

### 推送本地分支到远程仓库

```bash
git push origin 本地分支名
```

例如：

```bash
git push origin dev
```

本地分支不会自动同步到远程仓库，需要明确执行推送命令。

### 关联本地分支与远程分支

```bash
git branch --set-upstream-to=origin/远程分支名 本地分支名
```

例如：

```bash
git branch --set-upstream-to=origin/dev dev
```

## 查看分支

### 查看本地分支

```bash
git branch
```

查看更详细的本地分支信息：

```bash
git branch -v
```

输出示例：

```text
* master     2ab2384 Add new feature
  dev        abcd123 Fix bug
  feature-1  efgh456 Implement new function
```

星号标记的是当前所在分支。

### 查看所有本地和远程分支

```bash
git branch -a
```

### 查看远程分支

```bash
git branch -r
```

### 查看分支跟踪关系

```bash
git branch -vv
```

输出示例：

```text
* master 2ab2384 Add new feature [origin/master] [ahead 1, behind 1]
  dev    abcd123 Fix bug [origin/dev] [ahead 3]
```

## 切换分支

切换到已有分支：

```bash
git checkout branchName
```

创建并切换到新分支：

```bash
git checkout -b newBranch
```

基于远程分支创建本地分支：

```bash
git checkout -b zhanghanlun origin/zhanghanlun
```

如果本地分支已经存在，直接切换即可：

```bash
git checkout zhanghanlun
```

## 删除分支

### 删除本地分支

```bash
git branch --delete dev
```

也可以使用缩写：

```bash
git branch -d dev
```

强制删除：

```bash
git branch -D dev
```

说明：

- `-d` 是 `--delete` 的缩写，会检查分支是否已经合并。
- `-D` 是 `--delete --force` 的缩写，不检查合并状态，直接删除。

### 删除远程分支

```bash
git push origin --delete branch
```

### 删除本地远程跟踪分支

```bash
git branch --delete --remotes origin/branch
```

如果远程分支已经在网页上删除，本地仍保留跟踪分支，可以执行：

```bash
git fetch origin --prune
```

或使用缩写：

```bash
git fetch origin -p
```
