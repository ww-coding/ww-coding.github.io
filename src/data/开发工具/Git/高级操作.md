# Git 高级操作

## 多个 commit 合为一个

如果需要把多个连续 commit 合并为一个，可以使用交互式 rebase：

```bash
git rebase -i HEAD~3
```

这里的 `HEAD~3` 表示处理最近 3 个 commit。进入编辑界面后，保留第一个 commit 为 `pick`，将后续需要合并的 commit 改为 `squash` 或 `s`。

示例：

```text
pick 1111111 first commit
squash 2222222 second commit
squash 3333333 third commit
```

保存后，根据提示整理最终提交信息即可。

## rebase 后无法 push

### 问题现象

执行 push 时出现类似报错：

```text
error: failed to push some refs to 'xxx.git'
hint: Updates were rejected because the tip of your current branch is behind
! refs/heads/test:refs/heads/test [rejected] (non-fast-forward)
```

### 原因

本地分支和远程分支提交历史不一致，远程分支包含本地没有的提交，Git 拒绝非快进推送。

### 解决方法

先拉取远程变更并 rebase：

```bash
git pull --rebase origin master
```

再推送：

```bash
git push -u origin master
```

如果你已经确认远程提交可以被当前本地历史覆盖，才考虑使用强制推送：

```bash
git push --force-with-lease
```

`--force-with-lease` 会比 `--force` 更安全，它会在远程分支没有被其他人继续更新时才覆盖。

## rebase 到远程分支

常见流程：

```bash
git fetch origin
git rebase origin/分支名称
```

如果 rebase 过程中出现冲突：

```bash
git status
```

解决冲突后继续：

```bash
git add .
git rebase --continue
```

如果决定放弃本次 rebase：

```bash
git rebase --abort
```
