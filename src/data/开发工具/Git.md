# Git

Git 是日常开发中最常用的版本控制工具。本目录整理 Git 的基础命令、分支协作、常见问题处理以及 rebase、reset 等进阶操作，方便按场景快速查找。

## 内容目录

- [基础操作](./Git/基础操作.md)：初始化仓库、提交修改、查看状态与差异。
- [分支管理](./Git/分支管理.md)：创建、切换、关联、查看和删除分支。
- [问题排查](./Git/问题排查.md)：TortoiseGit safe.directory、reset 后未暂存变更等常见问题。
- [高级操作](./Git/高级操作.md)：rebase、合并 commit、rebase 后无法 push 等协作场景。
