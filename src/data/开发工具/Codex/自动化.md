# 自动化

Codex 可以用于提醒、定时检查、持续跟进等自动化任务。它适合处理“以后某个时间再做”或“周期性检查”的工作。

![Codex 能力关系图](../../../images/codex/codex-capability-map.svg)

## 适合自动化的任务

- 每天提醒复习某个知识点。
- 定期检查项目构建是否正常。
- 周期性跟进某个 issue 或 PR。
- 在指定时间提醒发布文章。
- 监控某个条件，满足后通知你。

## 使用方式

你可以自然语言描述时间和任务：

```text
明天上午 9 点提醒我继续完善 Codex 文档。
```

```text
每周五下午检查一次博客构建是否通过。
```

## 注意事项

- 自动化适合提醒和检查，不适合无确认地执行高风险操作。
- 涉及提交、发布、删除等操作时，应让 Codex 先通知你确认。
- 描述时间时尽量写清楚日期、时间和时区。

## 创建步骤

1. 说明触发时间，例如“每天上午 9 点”。
2. 说明要做什么，例如“检查博客构建是否通过”。
3. 说明完成后怎么通知你。
4. 如果任务涉及代码修改，要求 Codex 先等待确认。

示例：

```text
每周五下午 5 点提醒我检查博客文章是否需要更新，不要自动提交代码。
```
