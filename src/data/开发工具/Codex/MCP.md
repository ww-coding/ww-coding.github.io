# MCP

MCP 可以理解为 Codex 连接外部工具和数据源的一种协议。通过 MCP，Codex 可以访问本地工具、公司系统、文档平台、数据库、浏览器自动化能力等。

![Codex 能力关系图](../../../images/codex/codex-capability-map.svg)

## MCP 能做什么

- 查询外部文档。
- 读取授权后的私有数据。
- 调用项目专用工具。
- 操作浏览器或其他应用。
- 把团队内部系统接入 Codex。

## 什么时候需要 MCP

- Codex 需要实时数据，而不是只读本地文件。
- Codex 需要访问私有系统。
- Codex 需要调用一个稳定的外部工具。
- 单靠命令行或文件读写不够。

## 使用建议

- 优先使用官方或可信 MCP 服务。
- 私有数据要确认权限和访问范围。
- 不要把账号密码写进普通文档。
- 对外部操作保持可审计，重要操作前先确认。

## 示例

```text
使用 OpenAI 文档 MCP，查询 Codex 最新官方说明后再回答。
```

## 使用步骤

1. 确认 Codex 是否真的需要外部数据。
2. 选择可信的 MCP 服务。
3. 配置访问权限和连接方式。
4. 让 Codex 使用 MCP 查询或执行。
5. 对重要结果保留来源或验证记录。
