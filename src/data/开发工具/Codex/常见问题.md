# 常见问题

## Codex 会自动提交代码吗

一般不会。Codex 可以修改文件，但是否提交通常由你决定。你可以明确要求它提交，也可以自己使用 Git 提交。

## Codex 会覆盖我的代码吗

Codex 应该先检查当前工作区状态，并避免覆盖无关改动。为了更安全，可以在需求中明确说：

```text
不要覆盖我已有的未提交改动。
```

## Codex 能不能联网查资料

在允许网络访问的环境中可以。但涉及最新信息、官方文档、价格、政策等内容时，应优先查官方来源。

## Codex 适合完全自动写完整项目吗

更推荐把任务拆小：先做页面结构，再做功能，再做测试和优化。小步执行更容易检查，也更容易回滚。

## Codex 和 ChatGPT 有什么区别

Codex 更偏向在真实项目里工作：读文件、改代码、运行命令、看 diff、处理构建和测试。ChatGPT 更偏向对话、解释和通用问答。

## 我应该怎么给 Codex 提需求

说明四件事最有帮助：

- 目标是什么。
- 修改范围在哪里。
- 有哪些限制。
- 怎么验证算完成。
